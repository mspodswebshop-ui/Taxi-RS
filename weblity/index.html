Paylity

Payments made simple.

Mijn AI

Je eigen assistent, onder je eigen naam.

Een volledige chat-app op de Claude API: antwoorden die live binnenstromen, meerdere gesprekken, een modelkiezer, licht en donker thema en een instelbare persoonlijkheid. Abonnementen lopen via Stripe. De API-sleutel blijft op de server en komt nooit in de browser.

  • Claude API
  • Fable 5
  • Streaming
  • Node.js
  • Stripe
  • Netlify · Render

Scène 05 — Werkwijze

Van script tot première.

01

Script

We luisteren eerst. Wat moet je site doen, voor wie, en wat moet de bezoeker onthouden als hij weer weg is?

02

Storyboard

Het ontwerp, scherm voor scherm. Je ziet het verhaal voordat er één regel code geschreven is.

03

Opname

We bouwen. Snel, toegankelijk en strak op elk scherm, met animaties die iets vertellen in plaats van afleiden.

04

Première

Live. En daarna blijven we in de zaal: meten, bijsturen en verder bouwen aan het vervolg.
