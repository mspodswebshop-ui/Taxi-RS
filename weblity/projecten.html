Project 01 · Betaalplatform

Paylity

Payments made simple.

Een betaalplatform voor webshops. Je maakt een betaallink met een bedrag en een omschrijving, deelt hem en volgt alles in één dashboard. Wie zelf wil bouwen, koppelt via de REST API en krijgt ondertekende webhooks terug.

  • Betaallinks en een checkout met Bancontact en kaart
  • Dashboard met omzet, klanten, facturen en analytics
  • AI-assistent die in gewone taal vertelt wat er binnenkwam
  • Versie 1 draait in testmodus, klaar om een erkende betaalprovider te koppelen
  • Next.js
  • PostgreSQL
  • REST API
  • Webhooks
  • AI-assistent

Project 02 · AI-chatapp

Mijn AI

Je eigen assistent, onder je eigen naam.

Een volledige chat-app op de Claude API. Antwoorden stromen live binnen, je houdt meerdere gesprekken bij en kiest zelf het model en de persoonlijkheid van de assistent.

  • Streamende antwoorden met nette opmaak
  • Meerdere gesprekken, licht en donker thema
  • Abonnementen via Stripe
  • De API-sleutel blijft op de server en komt nooit in de browser
  • Claude API
  • Fable 5
  • Streaming
  • Node.js
  • Stripe
