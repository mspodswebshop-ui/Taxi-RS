# Lettertypes

Deze bestanden staan hier zodat `intake.html` geen verzoek naar Google's
servers doet. Dat scheelt een derde partij die het IP-adres van elke
bezoeker te zien krijgt — in de EU een reden tot boetes.

| Bestand | Familie | Herkomst |
|---|---|---|
| `inter-tight-latin.woff2`, `inter-tight-latin-ext.woff2` | Inter Tight (variabel, 100–900) | Google Fonts |
| `newsreader-latin.woff2`, `newsreader-latin-ext.woff2` | Newsreader (variabel, 200–800) | Google Fonts |

Beide zijn variabele fonts: één bestand dekt alle gewichten. De `latin-ext`
versies worden door de browser alleen opgehaald als een bezoeker daar
tekens uit nodig heeft — dat regelt de `unicode-range` in de stylesheet.

Beide staan onder de SIL Open Font License 1.1, zie `OFL-InterTight.txt`
en `OFL-Newsreader.txt`.
